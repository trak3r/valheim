## What it does

Removes the dense **Misty** whiteout fog weather — the thick soup that can roll in on the ocean, plains, and elsewhere.

## Why install it

Misty fog can blank out the horizon and make sailing or travel miserable. This keeps the skies clear of that weather without changing rain, storms, or Mistlands mist.

## How to use it

1. Install with BepInEx (same as other Valheim mods).
2. Play as usual — Misty whiteout weather simply never shows up.
3. If Misty was already active when you load in, it switches to clear.

Does **not** thin or remove Mistlands mist (that’s a different system — see Thinner Mist if you want that).

No config. Client-side only — works on any server.
