## What it does

Open a crafting station and every worn inventory item that station can repair is fixed immediately.

## Why install it

Skips hammering the repair button for every dinged tool and armor piece.

## How to use it

1. Install with BepInEx.
2. Open a station that can repair (workbench, forge, etc.).
3. Damaged items that belong to that station repair automatically.

Same rules as the vanilla repair hammer (forge still needs fire, etc.).

Client-side only — works on any server.
