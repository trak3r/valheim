## What it does

Processing stations pull fuel and inputs from chests within ~4 m — while running, and when you press E with empty hands.

## Why install it

Keeps kilns and smelters fed without constant hand-loading from adjacent storage.

## How to use it

1. Install with BepInEx.
2. Place chests with fuel/ore within ~4 m of the station intakes.
3. Let the station run, or press E empty-handed to top it up.

Kiln auto-feed uses plain wood only (fine/core wood stay manual).

Client-side convenience — works on any server.
