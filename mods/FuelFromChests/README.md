# Teflon Ted's Fuel From Chests

Kilns, smelters, furnaces, and windmills pull matching items from chests within about 2.5 meters of the intake — wood for kilns, coal/ore for smelters, barley for windmills — intentionally tight so general storage is not drained.

Also works when you press **E** on the station: if your bags are empty, it uses a nearby chest instead.
