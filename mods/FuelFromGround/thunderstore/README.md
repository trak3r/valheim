## What it does

Same stations as Fuel From Chests, but they suck matching item drops off the ground within ~4 m.

## Why install it

Lets you run kiln → smelter style assembly lines without picking up every stick of wood or lump of coal.

## How to use it

1. Install with BepInEx.
2. Drop or spit fuel/ore within ~4 m of the station.
3. Stations pull matching drops automatically.

Kilns only auto-suck plain wood. Frost Foundry pulls Liquid Frost drops; stone ovens do not auto-drain wood.

Client-side only — works on any server.
