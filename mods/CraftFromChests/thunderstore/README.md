## What it does

Craft, build, cook, and consume recipe materials using items in nearby chests — not only your backpack.

## Why install it

Stops the inventory shuffle when a recipe needs wood or iron that is already sitting in a chest a few steps away.

## How to use it

1. Install with BepInEx (same as other Valheim mods).
2. Stand near your storage (~20 m).
3. Craft or build as usual — inventory is used first, then accessible chests.
4. Requirement amounts show need (chests), e.g. 10 (42).

Only chests you can open count (wards / ownership respected).

Client-side convenience — works on any server.
