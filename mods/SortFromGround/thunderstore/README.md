## What it does

World item drops get sucked into nearby chests that already contain the same item (~4 m).

## Why install it

Kiln coal spit, loot piles, and crafting overflow land in storage instead of carpeting your floor.

## How to use it

1. Install with BepInEx.
2. Keep a chest seeded with the item within ~4 m of where drops land.
3. Play as usual — matching drops vacuum in after a short settle.

No config. Client-side only — works on any server.
