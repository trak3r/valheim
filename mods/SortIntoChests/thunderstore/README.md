## What it does

Press ` (backtick / tilde) to shove backpack items into nearby chests that already contain that item.

## Why install it

Ends the click-fest of restocking a seeded storage room after a haul.

## How to use it

1. Install with BepInEx.
2. Stand near your chests (~20 m).
3. Press ` — matching items leave the bag into seeded chests.

Hotbar and equipped gear stay put.

Client-side only — works on any server.
