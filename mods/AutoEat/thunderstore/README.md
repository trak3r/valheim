## What it does

When a food buff's timer hits zero, automatically eat the same food again if it is still in your inventory.

## Why install it

Keeps your three food slots topped without babysitting the timers mid-fight or mid-sail.

## How to use it

1. Install with BepInEx.
2. Keep stacks of your usual foods in inventory (including hotbar).
3. When a buff fully expires, that same food is re-eaten if available.

Does not eat early, pick \"best\" food, or pull from chests.

Client-side only — works on any server.
