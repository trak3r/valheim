## What it does

Snaps cultivator planting to a local grid so crops land in clean, optimally spaced rows.

## Why install it

Ends guessing \"needs room to grow\" and browning plants from cramped placement.

## How to use it

1. Install with BepInEx.
2. Plant with the cultivator — a green grid appears near existing crops.
3. Place on snapped cells to lock a clean field.

Spacing is per crop type (fat colliders like barley get room).

No config. Client-side only.
