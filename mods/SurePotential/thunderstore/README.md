## What it does

Forge of Potential (and similar upgrader stations) always succeed — 100% upgrade, 0% break.

## Why install it

Removes the 65% gamble that can destroy gear you already invested in.

## How to use it

1. Install with BepInEx.
2. Upgrade at the Forge of Potential as usual — idols still consumed, odds are certain.

In multiplayer, client and server should both run this so everyone sees the same odds.

Does not skip idol cost or change level caps.
