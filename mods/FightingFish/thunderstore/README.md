## What it does

When a hooked fish starts fighting, you get a clear **Stop reeling!** message in the center of the screen plus a short water splash sound.

## Why install it

Vanilla fishing only shows subtle thrashing and a stamina spike — easy to miss until the line breaks. This cue tells you the moment to ease off.

## How to use it

1. Install with BepInEx (same as other Valheim mods).
2. Fish as usual.
3. When **Stop reeling!** appears, stop blocking/reeling until the fish calms (message gone), then reel again.

No config. Client-side only — works on any server.
